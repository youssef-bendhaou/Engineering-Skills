# Information Filtering

## What is it?

Information Filtering means **finding the useful information and ignoring what is not relevant**.

Engineers can find information from many sources:

* Datasheets
* Reference manuals
* Documentation
* GitHub
* Forums
* Tutorials
* Technical articles

The challenge is knowing **which information can be trusted and used**.

## How do I filter information?

```text
Problem
   ↓
Define what I need
   ↓
Search
   ↓
Filter
   ↓
Check the source
   ↓
Verify
   ↓
Apply
```

## What should I check?

Before using information, ask:

* Is it related to my problem?
* Is the source reliable?
* Does it match my hardware?
* Does it match my software version?
* Can I verify it?

## Example

If I have a QNX problem, I may find information from:

```text
Official Documentation
        ↓
Technical Examples
        ↓
GitHub
        ↓
Forums
```

I should compare the information and verify it before applying it.

## Key Idea

> **Finding information is easy. Finding the right information is an engineering skill.**
