# Engineering Skills

A practical collection of engineering skills, methods and problem-solving approaches developed through embedded systems projects and technical work.

## Skills Covered

### 01 — Big Picture Thinking

Understanding the complete system and the interaction between its different components.

### 02 — Debugging

A structured approach to identifying, analyzing and solving technical problems.

### 03 — Datasheet Reading

Learning how to efficiently find and understand important technical information in datasheets and reference manuals.

### 04 — Information Filtering

Identifying relevant and reliable information from large amounts of technical documentation and online resources.

## Engineering Approach

These skills are interconnected:

```text
Understand the System
        ↓
Identify the Information Needed
        ↓
Read the Technical Documentation
        ↓
Analyze the Problem
        ↓
Debug and Test
        ↓
Verify the Solution
```

## Practical Application

The concepts presented in this repository are illustrated through examples related to:

* Embedded systems
* STM32
* ESP32
* Communication protocols
* Software debugging
* Technical documentation
* System architecture

## Goal

The goal of this repository is to document not only **what I know**, but also **how I approach engineering problems**.
