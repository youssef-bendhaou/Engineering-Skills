# Datasheet Reading

## What is it?

A datasheet is a technical document provided by the manufacturer.

It contains information needed to **understand and use a component correctly**.

## What can I find?

Depending on the component:

* Pinout
* Supply voltage
* Current
* Communication protocols
* Timing
* Registers
* Operating conditions
* Electrical limits

## How do I read it?

I don't need to read every page.

I start with the problem:

```text
Technical Problem
       ↓
What information do I need?
       ↓
Search keywords
       ↓
Find the relevant section
       ↓
Understand
       ↓
Apply
       ↓
Test
```

## Example

If I want to use an I²C sensor, I can search for:

* I²C address
* SDA / SCL
* Communication speed
* Registers
* Initialization
* Timing

## Key Idea

> **You don't need to memorize a datasheet. You need to know how to find the information you need.**
